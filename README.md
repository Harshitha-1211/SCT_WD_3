# SCT_WD_3

## SkillCraft Technology - Web Development Internship

### Task 3: Tic-Tac-Toe Web Application

This project is an interactive Tic-Tac-Toe Web Application developed using HTML, CSS, and JavaScript. The game allows two players to compete, automatically detects winning combinations, and handles draw conditions.

### Features

* Two-player gameplay (X and O)
* Automatic winner detection
* Draw detection
* Restart game functionality
* Responsive and interactive user interface

### Technologies Used

* HTML5
* CSS3
* JavaScript
